What the fds package does. Split, measure and train on four datasets.

Geometric splits of any dataset

k-means on DINOv2-B embeddings makes one cluster per client, and the number of clients sets how severe it gets.

Semantic splits along dataset criteria

Each image gets a value per criterion, and clients draw Dirichlet preferences over them. The labels for all four datasets ship with the code.

    Questions about FDS

    Does the simulation need labels?

    No. Geometric splits read pretrained embeddings and semantic splits read criteria a vision-language model assigns. Label skew stays in as a baseline.

    Which federated split should I use?

    Geometric for the hardest setting with one decision, the encoder. Semantic when clients should differ along named criteria, which you design per dataset.
