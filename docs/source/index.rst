FDS: Federated Learning Data Partitioning & Evaluation
=======================================================

Welcome to FDS (Federated Data Splitter), a comprehensive Python package for data partitioning, distribution evaluation, and federated learning research.

**FDS** provides tools for:

* **Data Partitioning**: Create realistic non-IID data splits for federated learning scenarios
* **Embedding Extraction**: Extract features using state-of-the-art foundation models
* **Distribution Metrics**: Evaluate data heterogeneity with statistical and feature-based metrics
* **FL Training**: Integration with NVIDIA FLARE for federated learning experiments
